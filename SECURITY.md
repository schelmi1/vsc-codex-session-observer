# Security policy

## Supported versions

Security fixes are made on the latest release and the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or for any report that
could include session data. Use GitHub's **Security** tab and **Report a
vulnerability** to create a private report for this repository. Include a
minimal reproduction and redact transcripts, credentials, tokens, paths, and
tool output.

If private vulnerability reporting is unavailable, contact the repository
maintainer through the GitHub profile linked from the repository owner page.

## Privacy boundary

This extension processes local Codex session metadata. A valid report must not
include a raw transcript or `auth.json`; describe the issue with synthetic data
instead.
