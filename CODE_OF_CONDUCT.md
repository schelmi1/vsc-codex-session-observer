# Code of Conduct

We want a respectful, constructive project for contributors and users.

Be considerate, discuss technical disagreements in good faith, and avoid
harassment, personal attacks, discriminatory language, or sharing anyone's
private session data. Respect the privacy rules in [CONTRIBUTING.md](CONTRIBUTING.md).

Maintainers may edit, remove, or reject contributions and discussions that do
not meet this standard. Report conduct concerns to a repository maintainer
without posting sensitive details publicly.
